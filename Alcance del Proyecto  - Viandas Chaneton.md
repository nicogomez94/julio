**1\. Objetivo del Proyecto**

Se propone el desarrollo de una web autoadministrable para Viandas Chaneton. La web estará orientada a mostrar productos, facilitar pedidos y permitir al cliente gestionar su propio contenido. Para su desarrollo, se tomará como referencia la demo visual compartida y el presupuesto enviado al cliente, donde la demo funciona como guía de estilo, secciones y presentación comercial.

**2\. Referencia Visual Tomada de la Demo**

La propuesta visual orienta la web a la venta y consulta de viandas, utilizando una imagen de marca casera y cercana.

Las **secciones visibles en la demo** son:

* Inicio con portada principal, mensaje comercial y llamados a la acción  
* Sección de productos destacados o especiales del día  
* Bloque de historia o presentación de la marca  
* Sección explicando cómo hacer un pedido  
* Botón destacado para contacto por WhatsApp  
* Datos de contacto, horarios y ubicación

Estas referencias definen la estructura general del sitio, pero no implican funcionalidades extra que no estén incluidas en el presupuesto.

**3\. Funcionalidades Incluidas**

**3.1. Que Incluye el Desarrollo**

* Página tipo *landing* con secciones de inicio, productos y contacto  
* Catálogo de productos para mostrar viandas, platos o promociones  
* Botón directo a WhatsApp para consulta o pedido  
* Integración con Google para mostrar la ubicación del negocio y facilitar que los clientes lo encuentren  
* Adaptación del contenido al estilo visual de la demo compartida  
* Panel de administración propio

**El Panel de Administración incluye:**

* Alta de productos  
* Edición de productos  
* Eliminación de productos  
* Organización de productos por categorías (por ejemplo, viandas, promos o especiales)

**3.2. Contenido que Puede Mostrar la Web**

* Foto de portada  
* Productos destacados  
* Descripción breve del negocio  
* Horarios  
* Datos de contacto  
* Ubicación

**4\. Panel de Administración**

El panel permite la gestión completa de productos: agregar, editar, eliminar y organizar por categorías.

**Precio de Referencia**

* Valor estimado informado al cliente: $100.000

**5\. Exclusiones del Alcance (Que No Incluye)**

* Ecommerce completo con pago online  
* Carrito de compras confirmado como funcionalidad final  
* Registro de usuarios  
* Login de clientes  
* Gestión de envíos en tiempo real  
* Integraciones con sistemas externos no mencionadas en el presupuesto  
* Carga masiva de productos  
* Redacción de textos, fotografía profesional o *branding* nuevo

**6\. Puntos a Confirmar**

Los siguientes puntos requieren definición por parte del cliente:

* Si los pedidos se van a cerrar solo por WhatsApp o también desde la web  
* Si la sección de historia de la marca queda incluida  
* Si se van a mostrar horarios, zonas de entrega y promociones especiales  
* Si Google se integrará como mapa embebido, botón de ubicación o ambas cosas  
* Si el cliente ya cuenta con logo, fotos y textos definitivos  
* Si las categorías de productos ya están definidas

**7\. Cierre**

La demo compartida es la referencia estética y comercial. El alcance funcional aprobado para desarrollo se refleja en este documento. Cualquier funcionalidad adicional o cambio de alcance fuera de este documento se considerará aparte.
