# Alcance del Proyecto

Preparado por ZigoDev
Fecha: 10 de mayo de 2026

## 1. Que vamos a hacer

Se propone una web para Viandas Chaneton tomando como referencia la demo visual compartida y el presupuesto enviado al cliente.

La demo funciona como guia de estilo, secciones y presentacion comercial. El alcance aprobado contempla una web autoadministrable orientada a mostrar productos, facilitar pedidos y permitir al cliente gestionar su contenido.

## 2. Referencia visual tomada de la demo

La propuesta visual muestra una web orientada a venta y consulta de viandas, con una imagen de marca casera y cercana.

Las secciones visibles en la demo son:

- Inicio con portada principal, mensaje comercial y llamados a la accion
- Seccion de productos destacados o especiales del dia
- Bloque de historia o presentacion de la marca
- Seccion explicando como hacer un pedido
- Boton destacado para contacto por WhatsApp
- Datos de contacto, horarios y ubicacion

Estas referencias sirven para definir la estructura general del sitio, pero no implican por si solas funcionalidades extra no incluidas en el presupuesto.

## 3. Funcionalidades incluidas

### Que incluye

- Pagina tipo landing con secciones de inicio, productos y contacto
- Catalogo de productos para mostrar viandas, platos o promociones
- Boton directo a WhatsApp para consultar o pedir
- Integracion con Google para mostrar la ubicacion del negocio y facilitar que los clientes lo encuentren
- Adaptacion del contenido al estilo visual de la demo compartida
- Panel de administracion propio
- Alta de productos
- Edicion de productos
- Eliminacion de productos
- Organizacion de productos por categorias, por ejemplo viandas, promos o especiales

### Contenido que puede mostrar la web

- Foto de portada
- Productos destacados
- Descripcion breve del negocio
- Horarios
- Datos de contacto
- Ubicacion

## 4. Panel de administracion

- Permite agregar productos
- Permite editar productos
- Permite eliminar productos
- Permite organizar productos por categorias

### Precio de referencia

- Valor estimado informado al cliente: $100.000

## 5. Que no incluye

- Ecommerce completo con pago online
- Carrito de compras confirmado como funcionalidad final
- Registro de usuarios
- Login de clientes
- Gestion de envios en tiempo real
- Integraciones con sistemas externos no mencionados en el presupuesto
- Carga masiva de productos
- Redaccion de textos, fotografia profesional o branding nuevo

## 6. Puntos a confirmar

- Si los pedidos se van a cerrar solo por WhatsApp o tambien desde la web
- Si la seccion de historia de la marca queda incluida
- Si se van a mostrar horarios, zonas de entrega y promociones especiales
- Si Google se integrara como mapa embebido, boton de ubicacion o ambas cosas
- Si el cliente ya cuenta con logo, fotos y textos definitivos
- Si las categorias de productos ya estan definidas

## 7. Cierre

La demo compartida sirve como referencia estetica y comercial para presentar mejor el negocio, y el alcance funcional de este documento refleja lo aprobado para desarrollo.

Cualquier funcionalidad adicional o cambio de alcance por fuera de este documento se toma como aparte.
